# lmd-technologies.cz
Web LMD Technologies s.r.o. – statické HTML, GitHub Pages z větve `main` (doména v `CNAME`).
Push do `main` = web se za ~1–2 min aktualizuje.

- Stránky: index, axion, konstrukce, automatizace, materialy, solidworks-pdm, circuitninja, o-nas, kontakt
- Obrázky a video: `img/`, animace Axionu: `js/axion-hero.js`, ikona: `favicon.*`, `apple-touch-icon.png`
- Kontaktní formulář odesílá přes FormSubmit.co na info@lmd-technologies.cz (bez serveru).
- Větev `stary-web` = záloha původního webu z Webglobe.
